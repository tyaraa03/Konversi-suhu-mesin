# Konversi-suhu-mesin
Pada penugasan ini saya membuat program untuk mengubah suhu mesin dari satuan Fahrenheit ke Celcius. Program meminta saya memasukkan nilai suhu dalam Fahrenheit, kemudian nilai tersebut dihitung menggunakan rumus konversi C = (F - 32) × 5/9. Dalam program ini digunakan tipe data float karena nilai suhu bisa memiliki angka desimal.
